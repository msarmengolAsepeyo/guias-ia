# Guías de IA

Guías visuales e interactivas para empezar con herramientas de IA. Cada guía es un único archivo HTML: descárgalo y ábrelo con doble clic en el navegador.

| Guía | Qué incluye |
|---|---|
| [`primeros-pasos.html`](primeros-pasos.html) | Primeros pasos con Claude Code: demo animada, ciclo de trabajo, peticiones para practicar, atajos y progreso. |
| [`perplexity-max.html`](perplexity-max.html) | Perplexity Max: uso normal, Model Council y Computer, costes, calculadora de créditos y cómo saber si Council se ejecuta dentro o fuera de Computer. |

La guía de Perplexity no es oficial. Usa datos recogidos el 8 de octubre de 2026 y los precios pueden cambiar.
